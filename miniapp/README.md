# ABC 字母乐园 · 微信小程序（简易版）

和网页版玩法一样（随便按、找字母、拼单词、每天限时、家长统计），多了 **AI 跟读评测和纠音**：

1. 点「🎤 跟我读」→ 放示范 →「该你读啦！」→ 录 3 秒
2. 放一遍她自己读的，同时交给**腾讯云口语评测**打分（单词模式，评分系数 1.0 = 最宽松的低龄档）
3. 按分数给 3 / 2 / 1 颗星，配中文鼓励语音；没读准的那个字母**标红**，说「听，这个地方要这样读」，再**放慢**放一遍示范；没出声就说「大声一点再读一次」
4. 家长页能看到每次评测的单词、分数和要练的音

**状态**：代码写好了，还没在微信开发者工具里跑过，没有 AppID，没上线。等营业执照下来注册小程序后按下面步骤上线。

## 上线步骤

### 1. 注册小程序

- 用营业执照（企业 / 个体户主体）注册，拿到 AppID，填进 `project.config.json` 的 `appid`（现在是 `touristappid` 游客模式）。
- 类目：面向儿童的学英语工具，**教育类目一般要资质**；先在后台「服务类目」里看能选什么，别自己猜。
- 涉及儿童录音：要在《隐私保护指引》里写明「麦克风：用于跟读评测，录音发送腾讯云评测后不保存」。小程序第一次跟读时会弹窗请家长同意（`pages/index/index.js` 的 `followMe`）。

### 2. 开通云开发

开发者工具里点「云开发」开通环境，把环境 ID 填进 `miniprogram/config.js` 的 `ENV`。

### 3. 上传发音文件

云开发控制台 →「存储」→ 新建文件夹 `audio` → 把仓库根目录 `audio/` 里的 **全部 mp3** 上传进去（约 250 个，7MB 左右）。
点开任意一个文件，复制它的 **File ID**，去掉文件名，得到形如 `cloud://xxx.xxxx-xxx-1300000000/audio/` 的前缀，填进 `config.js` 的 `AUDIO_BASE`。

> 发音不放进小程序包里：主包最多 2MB，mp3 有 7MB。

### 4. 部署评测云函数 `soe`

1. 腾讯云控制台开通「**口语评测（新版）**」，核对计费页上的免费额度和单价。
2. 访问管理 → 新建**子账号**（编程访问），只授权 `QcloudSOEFullAccess`，记下 SecretId / SecretKey。
3. 开发者工具里右键 `cloudfunctions/soe` →「上传并部署：云端安装依赖」。
4. 云开发控制台 → 云函数 `soe` → 配置 → 环境变量，填三项（**只填在这里，不要写进代码、不要发到聊天里**）：

| 变量 | 填什么 |
|---|---|
| `SOE_SECRET_ID` | 子账号 SecretId |
| `SOE_SECRET_KEY` | 子账号 SecretKey |
| `SOE_APPID` | 腾讯云账号的 AppID（控制台右上角「账号信息」里的数字） |

5. 超时时间改成 **30 秒**（评测要连 WebSocket，默认 3 秒不够）。

没配评测时小程序照样能用：跟读后只再放一遍示范，不出分数。

### 5. 真机试

先用自己的声音、再让孩子读几个单词，看分数和纠音是否合理。**4 岁孩子读单个单词，分数会有波动**，只用来给星星鼓励，不当考试分。觉得太严 / 太松，改 `rec.js` 里传给云函数的 `coeff`（1.0 最宽松，4.0 最严）。

## 改单词

单词表在仓库根目录 `tools/words.json`，改完：

```bash
node tools/sync-words.js     # 同步到小程序 utils/words.js
node tools/gen-audio.js      # 补生成新单词的发音（需要 .minimax-key）
```

再把新 mp3 上传到云存储 `audio/`。网页版 `index.html` 里的 `DATA` 也要同步改。

## 测试（电脑上就能跑，不用开发者工具）

```bash
node miniapp/test/page.test.js          # 模拟微信接口，走一遍三种玩法、跟读评测、家长页、限时
node miniapp/cloudfunctions/soe/test.js # 模拟腾讯云评测，测签名、打分分档、找出没读准的音、出错提示
```

## 文件

| 位置 | 作用 |
|---|---|
| `miniprogram/pages/index` | 主页面：三种玩法、屏幕键盘、跟我读、休息页 |
| `miniprogram/pages/parent` | 家长页：乘法题门槛、今日统计、7 天柱状图、评测记录、每天时长 |
| `miniprogram/utils/game.js` | 玩法逻辑（不依赖微信接口） |
| `miniprogram/utils/sound.js` | 连播云存储里的 mp3 |
| `miniprogram/utils/rec.js` | 录音 + 调评测云函数 |
| `miniprogram/utils/stats.js` | 每日统计、限时（存在手机本地） |
| `cloudfunctions/soe` | 腾讯云口语评测（密钥只在云函数环境变量里） |
