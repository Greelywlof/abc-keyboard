# 🌈 ABC 字母乐园

给 4 岁小朋友认英文字母的网页小游戏。一个 `index.html`，双击就能用，不用联网、不用安装。

## 两种玩法

- **🎹 随便按**：按键盘上任何字母，屏幕出现大字母 + 图片，并读出「字母名 + 单词」（如 *"bee. bee is for Ball."*）。每个字母有两个单词轮换；数字键 0–9 会显示对应个数的星星。
- **🔍 找字母**：屏幕出一个字母，让孩子在键盘上找。按错不扣分，只会轻轻摇一下并亮起提示键；8 秒没找到也会自动提示。按对放彩带、加一颗星。

- **✏️ 拼单词**：出图片和整个单词，照着一个一个敲。下一个要敲的格子在跳、对应的键在屏幕键盘上亮着；每敲对一个读出这个字母，敲错只会提醒该敲哪个；全部敲完响一声「耶！」、放彩带，再读一遍整个单词。点格子可以听那个字母。

孩子不认字，所以所有提示都有配音：中文告诉她做什么（「找一找，这个字母在哪里？」「不对哦，看看亮起来的那个键！」「太棒啦！」），英文读字母和单词。

## 🎤 跟我读

随便按、拼单词时，单词下面有「跟我读」按钮：先放示范 →「该你读啦！」→ 录 3 秒 → 放她自己读的 → **AI 打分**（腾讯云口语评测，低龄最宽松档）：3 / 2 / 1 颗星 + 分数，没读准的字母**标红**，说「听，这个地方要这样读」，再放慢放一遍示范。

- 评测走云函数 `cloud/abcsoe`（HTTP 路径 `/abc-soe`，和网页同一个腾讯云开发环境），只认单词表里的词、限制频率；密钥在本机 `.soe-key`（不上传），`node tools/deploy-soe.js` 部署。
- 费用：腾讯云口语评测（新版）按量 5 元 / 千次（11-16 控制台显示）。
- 11-16 真实测试：MiniMax 标准读音 Cat / Apple / Elephant 得 98–99 分；把 Dog 的录音当 Cat 评得 32 分，标出 a 没读准。
- 录音只在内存里，评完不保存；家长面板里可以回听本次打开后的录音和分数。

## 🏅 总结卡片 · 勋章 · 成长档案

- 时间到了出现**总结卡片**（全部配音）：今天的奖牌、拼对几个单词（用图画）、跟读几次、最好一次几颗星、今天新得的徽章、我的奖牌柜。
- **每天一枚奖牌**：来玩就有 🥉；拼对 3 个单词或跟读 5 次 🥈；拼对 6 个并跟读 6 次 🥇。
- **收集徽章**（每个只拿一次）：第一次拼对单词、第一次三颗星、学会 10/26/52 个单词、26 个字母全按过、连续 3/7 天、一天跟读平均 90 分。
- 家长面板「📜 成长档案」：玩过的天数、学会的单词、一共拼对 / 跟读、平均分、连续天数、奖牌数、徽章墙、最近 30 天日历、学会的单词列表。档案长期保存在这台设备的浏览器里。
- 规则在 `medals.js`（网页和小程序共用，`node tools/sync-words.js` 同步），测试 `node tools/medals.test.js`。

## ⏱ 每天限时 + 📊 统计（家长）

- 默认每天 **15 分钟**，剩 1 分钟语音提醒，到点出现休息页、键盘不再响应，第二天自动恢复。
- 右上角 👪 进家长面板（要先答一道乘法题）：今天拼对的单词（和单词列表）、按的字母、找对的字母、跟读次数、已玩分钟；最近 7 天拼对单词的柱状图；改每天时长（5–30 分钟）、「今天再加 5 分钟」；回听录音。
- 数据存在这台设备的浏览器里（localStorage），换设备、清浏览器数据会清零。

## 点一下重读

- 点**提示语**或（找字母时）**大字母** → 再听一遍题目

- 点**大字母** → 只读字母
- 点**图片或单词** → 只读单词

## 家长按钮

- `Aa`：切换大写 / 小写
- `🔊`：静音
- `⛶`：全屏（防止孩子乱点到别处）

按键时会屏蔽浏览器快捷键，Ctrl/Alt 组合键和 Esc、F11 留给家长。

## 发音

优先播放 `audio/` 里用 **MiniMax 语音合成**预先生成的 mp3；没有这些文件时自动退回浏览器自带语音（Chrome / Edge 效果较好）。

生成 / 重新生成发音（Key 只放本机，不会进仓库）：

```bash
# 把 MiniMax API Key 单独一行存到 .minimax-key（已被 .gitignore 排除）
node tools/gen-audio.js voices   # 看可用英文音色
node tools/gen-audio.js          # 生成全部 mp3（已有的跳过；--force 重做）
```

可用环境变量换音色：`MINIMAX_VOICE`（英文，默认 `English_radiant_girl`）、`MINIMAX_VOICE_ZH`（中文，默认 `female-tianmei`）。改单词时同时改 `index.html` 里的 `DATA` 和 `tools/words.json`。
